---
title: Installation
description: Install Minions Services packages
---

## TypeScript / Node.js

```bash
npm install @minions-services/sdk minions-sdk
```

## Python

```bash
pip install minions-services
```

## CLI

```bash
npm install -g @minions-services/cli
```

## Requirements

- **Node.js** 20 or later
- **Python** 3.11 or later (for Python SDK)
