# Minions Services

Service catalog, packages, pricing tiers, case studies, and target industries

## Overview

This project is part of the [Minions ecosystem](https://github.com/mxn2020/minions) and provides:

- **TypeScript SDK** (`@minions-services/sdk`) — Core library for Node.js
- **Python SDK** (`minions-services`) — Python bindings
- **CLI Tool** (`@minions-services/cli`) — Command-line interface
- **Web App** — Interactive playground at [services.minions.wtf](https://services.minions.wtf)
